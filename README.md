## FAQ

### What is XCutors and what does it do?

XCutors is a curated collection of Windows-based tools for the Roblox platform. It provides a single launcher to manage and run various script executors, allowing you to execute custom Lua scripts in Roblox games.

### Is using XCutors safe for my computer?

The tools are scanned and packaged for distribution, but execution of third-party scripts carries inherent risk. We recommend running XCutors in a secure environment and only using scripts from trusted sources.

### How do I update the executors in the collection?

Check the GitHub repository's 'Releases' page regularly for new XCutors versions. Updates will include patched versions of the bundled executors to ensure continued compatibility with Roblox updates.

### Can I add my own executor to the XCutors collection?

The current version is a fixed collection. Advanced users can modify the configuration files to include other compatible loaders, but this is not officially supported and may break functionality.

### Why do some scripts not work with certain executors?

Different executors have varying levels of support for specific Lua functions and game environment hooks. If a script fails, try switching to another executor within XCutors like Synapse Z or Volt.

### Does XCutors work on Windows 11 and older versions?

Yes, XCutors is designed to be compatible with Windows 10 and Windows 11. Ensure your system meets the minimum .NET Framework and Visual C++ Redistributable requirements for the tools to run properly.

### What is the password for the downloaded archive?

The password is typically provided in the release description on the GitHub page or in a PASSWORD.txt file included in the main repository. Always check the latest release notes for the current password.

### How can I report an issue with an included executor?

Open an issue on the GitHub repository with a clear description of the problem, the executor you were using, and the script you attempted to run. Provide any error logs from the XCutors console if available.
